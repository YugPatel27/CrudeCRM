# CrudeCRM
CrudeCRM is a PHP-based CRM system designed to manage business operations such as clients, leads, inventory, invoices, and users in one place.

Features -
**Client Management**
Add, update, and organize client information with ease.
**Lead Management**
Track potential customers, monitor progress, and convert leads into clients.
**Inventory & Product Tracking**
Manage product listings, stock levels, and inventory records.
**Invoice Management**
Create, update, and manage invoices for clients efficiently.
**User Authentication & Management**
Secure login/logout system with user profile management.
**Activity Logs & Reporting**
Track system activities and generate reports such as inventory summaries.
